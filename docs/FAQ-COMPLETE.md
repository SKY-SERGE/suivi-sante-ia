# FAQ - Questions Fréquemment Posées - Suivi Santé IA

## 🎯 Questions générales

### 🤔 Qu'est-ce que Suivi Santé IA ?

**Suivi Santé IA** est une plateforme de suivi alimentaire et de santé qui utilise l'intelligence artificielle pour :

- 📷 **Analyser vos repas** par photo automatiquement
- 🎯 **Suivre vos objectifs** santé personnalisés
- 💬 **Répondre à vos questions** via un chatbot intelligent
- 👨‍⚕️ **Faciliter le suivi médical** avec votre médecin (optionnel)
- 📊 **Visualiser vos progrès** avec des graphiques détaillés

### 🆓 L'application est-elle gratuite ?

**Oui**, toutes les fonctionnalités principales sont **gratuites** :

- ✅ Analyse illimitée de photos de repas
- ✅ Chatbot IA santé
- ✅ Suivi d'objectifs personnalisés
- ✅ Graphiques et statistiques
- ✅ Communication avec votre médecin
- ✅ Stockage sécurisé de vos données

### 🔐 Mes données sont-elles sécurisées ?

**Absolument !** Votre sécurité est notre priorité :

- 🔒 **Chiffrement AES-256** de toutes vos données
- 🛡️ **Conformité RGPD** et HDS (Hébergement Données de Santé)
- 🚫 **Aucune vente** de données à des tiers
- 🏥 **Certification médicale** pour le stockage des données de santé
- 🔍 **Audits de sécurité** réguliers

### 📱 Sur quels appareils puis-je utiliser l'application ?

**Tous les appareils modernes** :

- 💻 **Ordinateur** : Windows, Mac, Linux (navigateur web)
- 📱 **Smartphone** : iOS 12+, Android 8+ (navigateur mobile)
- 🎨 **Tablette** : iPad, Android (interface adaptée)
- 🌐 **Navigateurs** : Chrome, Firefox, Safari, Edge (versions récentes)

**Aucune installation** requise - tout fonctionne dans votre navigateur !

## 🍽️ Questions sur l'analyse des repas

### 📷 Comment bien photographier mes repas ?

**Tips pour des photos parfaites** :

```
✅ BON ÉCLAIRAGE
├── Lumière naturelle (près d'une fenêtre)
├── Éviter l'ombre de votre téléphone
└── Pas de contre-jour

✅ ANGLE ET DISTANCE
├── Vue du dessus (plongée 45°)
├── Distance 30-50 cm de l'assiette
└── Cadrer toute l'assiette

✅ CLARTÉ
├── Photo nette (attendre la mise au point)
├── Assiette entière visible
└── Aliments bien séparés visuellement
```

### 🤖 Pourquoi l'IA n'identifie pas bien certains aliments ?

**L'IA a ses limites** - c'est normal ! Elle fonctionne mieux avec :

- ✅ **Aliments distincts** et reconnaissables
- ✅ **Préparations simples** (grillés, vapeur, crus)
- ✅ **Ingrédients classiques** européens/français

**Plus difficile pour** :

- ❌ Plats en sauce ou mélangés
- ❌ Cuisines exotiques moins connues
- ❌ Préparations très transformées
- ❌ Aliments industriels emballés

**Solution** : Vous pouvez toujours **corriger manuellement** l'analyse !

### 📊 L'application calcule-t-elle les calories ?

**Pour le moment, non.** Notre IA se concentre sur :

- 🍎 **Identification des aliments** (légumes, protéines, féculents...)
- 🎨 **Équilibre visuel** de l'assiette
- 📈 **Tendances alimentaires** générales
- 💡 **Recommandations qualitatives** (plus de légumes, variété...)

**Pourquoi pas de calories ?**

- Estimer précisément les quantités par photo est très complexe
- Nous privilégions l'approche **qualitative** et l'**équilibre**

### 🔄 Puis-je modifier l'analyse de l'IA ?

**Oui, c'est recommandé !** Voici comment :

1. **Après l'analyse**, cliquez sur "Modifier"
2. **Ajoutez** les aliments non détectés
3. **Supprimez** les erreurs d'identification
4. **Précisez** les quantités si souhaité
5. **Sauvegardez** vos corrections

Vos corrections **améliorent** l'IA pour vos prochaines analyses !

## 🎯 Questions sur les objectifs

### 📋 Quels types d'objectifs puis-je créer ?

**Objectifs alimentaires** :

- 🥗 "Manger 5 fruits et légumes par jour"
- 💧 "Boire 2 litres d'eau quotidiennement"
- 🐟 "Poisson 2 fois par semaine"
- 🍞 "Réduire les produits industriels"

**Objectifs lifestyle** :

- 🚶 "Marcher 10 000 pas par jour"
- 😴 "Dormir 8h par nuit"
- 🧘 "Méditer 10 min quotidiennement"
- ⚖️ "Maintenir mon poids stable"

**Objectifs mesurables** :

- 📊 "Perdre 5 kg en 3 mois"
- 💪 "Faire du sport 3 fois par semaine"
- 📱 "Photographier tous mes repas"

### 🎯 Comment l'application suit mes objectifs ?

**Suivi automatique** quand c'est possible :

- 📷 Photos de repas → Analyse automatique des légumes, protéines...
- 💬 Chatbot → Questions sur votre sommeil, hydratation...
- 📊 Saisie manuelle → Poids, activité physique...

**Suivi semi-automatique** :

- ✅ Validation simple "Objectif atteint aujourd'hui ?"
- 📝 Notes rapides sur vos ressentis
- 📈 Graphiques de progression automatiques

### 📈 Que faire si je n'atteins pas mes objectifs ?

**Pas de panique !** C'est normal et constructif :

1. **Analysez les obstacles** :

   - Objectifs trop ambitieux ?
   - Manque de temps ?
   - Motivation fluctuante ?

2. **Ajustez vos objectifs** :

   - Réduisez la fréquence temporairement
   - Décomposez en micro-objectifs
   - Célébrez les petites victoires

3. **Utilisez l'aide de l'IA** :

   - Demandez des conseils au chatbot
   - Consultez les recommandations personnalisées
   - Explorez les suggestions d'adaptation

4. **Partagez avec votre médecin** (si lié) pour des conseils adaptés

## 💬 Questions sur le chatbot IA

### 🤖 À quoi sert le chatbot santé ?

**Le chatbot peut vous aider pour** :

- ❓ **Questions générales** sur la nutrition
- 💡 **Conseils** pour une alimentation équilibrée
- 📚 **Informations** factuelles sur les aliments
- 🎯 **Suggestions** pour atteindre vos objectifs
- 🔍 **Explications** sur l'analyse de vos repas

**Important** : Ce n'est **pas un médecin** ! Il ne fait pas de diagnostic.

### ⚠️ Le chatbot peut-il me donner des conseils médicaux ?

**Non, absolument pas !** Le chatbot :

- ✅ **Peut** : Donner des informations générales sur la nutrition
- ✅ **Peut** : Expliquer l'équilibre alimentaire
- ✅ **Peut** : Suggérer des recettes saines
- ❌ **Ne peut pas** : Diagnostiquer une maladie
- ❌ **Ne peut pas** : Prescrire un traitement
- ❌ **Ne peut pas** : Remplacer un médecin

**En cas de problème de santé** → Consultez un professionnel !

### 🗣️ Comment bien utiliser le chatbot ?

**Questions efficaces** :

```
✅ "Comment équilibrer un petit-déjeuner ?"
✅ "Quels légumes contiennent le plus de vitamine C ?"
✅ "Idées de collations saines"
✅ "Comment cuisiner les lentilles ?"

❌ "Ai-je le diabète ?" (question médicale)
❌ "Quel médicament prendre ?" (prescription)
❌ "fdgfdg" (question incompréhensible)
```

**Conseils** :

- 🇫🇷 Écrivez en **français correct**
- ❓ **Une question** à la fois
- 📝 Soyez **précis** dans votre demande
- 🔄 **Reformulez** si la réponse ne convient pas

## 👨‍⚕️ Questions médecin-patient

### 🤝 Comment partager mes données avec mon médecin ?

**2 méthodes possibles** :

**Méthode 1 - Invitation du médecin** :

1. Votre médecin vous envoie une **invitation**
2. Vous recevez un **email** avec un lien
3. Vous **acceptez** le partage
4. **Choisissez** quelles données partager

**Méthode 2 - Recherche du médecin** :

1. Dans votre profil, cliquez **"Lier un médecin"**
2. **Recherchez** par nom ou numéro RPPS
3. **Envoyez** une demande de liaison
4. **Attendez** l'acceptation du médecin

### 🔒 Quelles données le médecin peut-il voir ?

**Vous contrôlez tout !** Vous pouvez partager :

- ✅ **Repas et analyses IA** (optionnel)
- ✅ **Objectifs et progrès** (optionnel)
- ✅ **Historique d'interactions** avec le chatbot (optionnel)
- ✅ **Données anthropométriques** (poids, taille...) (optionnel)
- ✅ **Messagerie** médecin-patient (automatique)

**Le médecin ne voit que ce que vous autorisez !**

### 🚫 Puis-je arrêter le partage à tout moment ?

**Oui, c'est votre droit !** Vous pouvez :

- ⏸️ **Suspendre temporairement** le partage
- 🔒 **Restreindre** certaines données
- 🚫 **Arrêter complètement** la liaison
- 🗑️ **Supprimer** l'historique partagé

**Comment** : Profil → Médecins liés → Gérer les autorisations

### 💬 Comment communiquer avec mon médecin ?

**Messagerie sécurisée intégrée** :

- 🔐 **Chiffrée** de bout en bout
- 📱 **Notifications** en temps réel
- 📎 **Pièces jointes** possibles (photos, documents)
- 📚 **Historique** conservé

**Bonnes pratiques** :

- ⏰ Questions **non urgentes** uniquement
- 🚨 **Urgences** → Appelez directement ou allez aux urgences
- 📝 Soyez **précis** dans vos messages
- 🙏 **Respectez** les horaires de votre médecin

## 🔧 Questions techniques

### 🌐 Puis-je utiliser l'application hors ligne ?

**Partiellement** :

- ✅ **Consultation** de vos données déjà téléchargées
- ✅ **Navigation** dans votre historique
- ❌ **Analyse IA** des photos (nécessite internet)
- ❌ **Chatbot** (nécessite internet)
- ❌ **Synchronisation** avec le médecin

**Conseil** : Utilisez une **connexion stable** pour l'expérience complète.

### 📱 Y a-t-il une application mobile ?

**Non, mais pas besoin !** Notre application web est **optimisée mobile** :

- 📱 **Interface adaptée** à votre écran
- 📷 **Accès caméra** pour les photos
- 🔔 **Notifications** web (si autorisées)
- 💾 **Mise en cache** pour la rapidité
- 🔄 **Synchronisation** automatique

**Avantage** : Pas d'installation, toujours à jour !

### 💾 Combien de place prennent mes données ?

**Très peu !** En moyenne par utilisateur actif :

- 📸 **Photos** : ~50-100 MB/mois (compressées automatiquement)
- 📊 **Données** : ~1-5 MB/mois (texte, graphiques)
- 💬 **Messages** : ~0.1-1 MB/mois

**Total** : Moins de 150 MB/mois même pour un usage intensif.

### 🔄 Puis-je exporter mes données ?

**Oui, c'est votre droit RGPD !**

**Formats disponibles** :

- 📄 **PDF** : Rapport lisible avec graphiques
- 📊 **CSV** : Données brutes pour analyse
- 🖼️ **ZIP** : Archive complète avec photos

**Comment** :

1. Profil → Paramètres → **"Exporter mes données"**
2. **Choisissez** la période et le format
3. **Recevez** le lien de téléchargement par email
4. **Téléchargez** (lien valide 7 jours)
