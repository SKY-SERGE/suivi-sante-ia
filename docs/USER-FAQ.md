## Questions Générales

### **Q : Qu'est-ce que la plateforme Suivi Santé IA ?**

**R :** C'est une plateforme numérique qui permet aux patients de suivre leur santé quotidiennement, aux médecins de surveiller leurs patients à distance, et qui utilise l'intelligence artificielle pour fournir des analyses et recommandations personnalisées.

### **Q : Qui peut utiliser cette plateforme ?**

**R :** La plateforme s'adresse à trois types d'utilisateurs :

- **Patients** : Pour le suivi personnel de santé
- **Médecins** : Pour le suivi de leurs patients (avec consentement)
- **Administrateurs** : Pour la gestion de la plateforme

### **Q : La plateforme est-elle gratuite ?**

**R :** Les conditions d'utilisation et de tarification dépendent de votre profil. Contactez notre équipe commerciale pour plus d'informations sur les plans disponibles.

### **Q : Sur quels appareils puis-je utiliser la plateforme ?**

**R :** La plateforme est accessible via navigateur web sur :

- **Ordinateurs** (Windows, Mac, Linux)
- **Tablettes** (iOS, Android)
- **Smartphones** (iOS, Android)
- Une application mobile dédiée sera disponible prochainement

### **Q : Mes données sont-elles sécurisées ?**

**R :** Oui, absolument. La plateforme respecte les plus hauts standards de sécurité :

- Chiffrement de bout en bout
- Conformité RGPD et certification HDS
- Hébergement sécurisé en France
- Audits de sécurité réguliers

## Compte et Authentification

### **Q : Comment créer un compte ?**

**R :**

1. Rendez-vous sur la page d'inscription
2. Choisissez votre type de compte (Patient/Médecin)
3. Remplissez le formulaire avec vos informations
4. Validez votre email
5. Pour les médecins : attendez la validation administrative

### **Q : Pourquoi mon compte médecin n'est-il pas encore activé ?**

**R :** Les comptes médecins nécessitent une validation manuelle par nos administrateurs pour vérifier :

- L'authenticité du numéro d'ordre des médecins
- Les diplômes et certifications
- Les documents justificatifs d'exercice
  Ce processus prend généralement 24-48h ouvrables.

### **Q : J'ai oublié mon mot de passe, que faire ?**

**R :**

1. Cliquez sur "Mot de passe oublié ?" sur la page de connexion
2. Saisissez votre adresse email
3. Consultez votre boîte mail (vérifiez les spams)
4. Suivez le lien pour réinitialiser votre mot de passe

### **Q : Comment activer l'authentification à deux facteurs (2FA) ?**

**R :**

1. Accédez à vos paramètres de compte
2. Section "Sécurité"
3. Activez "Authentification à deux facteurs"
4. Scannez le QR code avec votre application d'authentification
5. Saisissez le code de vérification

### **Q : Puis-je changer mon adresse email ?**

**R :** Oui, dans vos paramètres de profil, section "Informations personnelles". Vous devrez confirmer la nouvelle adresse email.

## Saisie et Gestion des Données

### **Q : Quels types de données puis-je saisir ?**

**R :** Vous pouvez enregistrer :

- **Données physiologiques** : poids, tension, fréquence cardiaque, température
- **Bien-être** : humeur, qualité du sommeil, niveau de stress
- **Activité** : exercice physique, nombre de pas
- **Alimentation** : repas (saisie manuelle ou photo)
- **Symptômes** : douleurs, effets secondaires
- **Médicaments** : prises et observance

### **Q : Comment fonctionne l'analyse de photo de repas ?**

**R :**

1. Prenez une photo claire de votre repas
2. L'IA Google Vision analyse l'image
3. Elle identifie les principaux groupes d'aliments
4. Vous recevez un feedback qualitatif général
5. L'analyse est stockée dans votre historique

**Note :** Cette fonctionnalité fournit des indications générales, pas d'estimation nutritionnelle précise.

### **Q : Dois-je saisir des données tous les jours ?**

**R :** Non, c'est flexible. Cependant, une saisie régulière améliore :

- La qualité des analyses IA
- Le suivi de vos tendances
- L'efficacité du suivi médical
- La pertinence des recommandations

### **Q : Puis-je modifier ou supprimer des données saisies ?**

**R :** Oui, vous pouvez :

- **Modifier** vos données dans un délai de 24h
- **Supprimer** des entrées erronées
- **Ajouter** des commentaires explicatifs
- L'historique des modifications est conservé pour traçabilité

### **Q : Mes données peuvent-elles être perdues ?**

**R :** Non, vos données sont :

- **Sauvegardées** automatiquement et en temps réel
- **Stockées** de manière redondante
- **Synchronisées** entre vos appareils
- **Protégées** par nos systèmes de backup

## Analyses IA et Recommandations

### **Q : Comment l'IA analyse-t-elle mes données ?**

**R :** L'IA utilise :

- **Analyse de tendances** dans vos données historiques
- **Comparaison** avec des patterns de santé reconnus
- **Algorithmes** de détection d'anomalies
- **Modèles** d'apprentissage automatique spécialisés

### **Q : Les recommandations IA sont-elles fiables ?**

**R :** Les recommandations IA sont des **outils d'aide** qui :

- Fournissent des suggestions générales basées sur vos données
- **Ne remplacent jamais** un avis médical professionnel
- Ont des **marges d'erreur** et limitations
- Doivent être **validées** par votre médecin

### **Q : Pourquoi les recommandations changent-elles ?**

**R :** Les recommandations évoluent car :

- L'IA **apprend** de vos nouvelles données
- Vos **habitudes** et **état de santé** changent
- Les **algorithmes** sont régulièrement mis à jour
- Le **contexte** saisonnier ou personnel influence l'analyse

### **Q : Puis-je désactiver certaines analyses IA ?**

**R :** Oui, dans vos paramètres, section "Intelligence Artificielle", vous pouvez :

- Désactiver les analyses alimentaires
- Suspendre les recommandations
- Choisir les types d'analyses actives
- Ajuster la fréquence des analyses

### **Q : L'IA peut-elle détecter des problèmes de santé ?**

**R :** L'IA peut **signaler des anomalies** ou tendances préoccupantes, mais :

- Elle **ne pose pas de diagnostic**
- Elle **ne remplace pas** un examen médical
- Elle fournit des **alertes** à discuter avec votre médecin
- Seul un **professionnel de santé** peut interpréter médicalement

## Communication Médecin-Patient

### **Q : Comment connecter mon compte à mon médecin ?**

**R :**

1. Demandez à votre médecin s'il utilise la plateforme
2. Dans votre interface, section "Mon Médecin"
3. Cliquez sur "Demander une liaison"
4. Saisissez l'identifiant ou email de votre médecin
5. Attendez l'approbation de votre médecin

### **Q : Mon médecin peut-il voir toutes mes données ?**

**R :** Votre médecin ne voit que les données pour lesquelles vous avez donné votre **consentement explicite**. Vous contrôlez :

- **Quelles données** partager
- **Période** de partage
- **Révocation** possible à tout moment
- **Historique** des accès consultable

### **Q : Comment révoquer l'accès de mon médecin ?**

**R :**

1. Accédez à "Mon Médecin" > "Consentements"
2. Cliquez sur "Révoquer l'accès"
3. Confirmez votre décision
4. L'accès est immédiatement supprimé
5. Votre médecin en est automatiquement notifié

### **Q : La messagerie avec mon médecin est-elle sécurisée ?**

**R :** Oui, absolument :

- **Chiffrement** de bout en bout
- **Traçabilité** complète des échanges
- **Conformité** aux exigences médicales
- **Archivage** sécurisé légal

### **Q : Mon médecin peut-il modifier mes données ?**

**R :** Non, votre médecin ne peut que :

- **Consulter** vos données partagées
- **Ajouter** des commentaires médicaux
- **Envoyer** des messages
- **Configurer** des alertes personnalisées

## Confidentialité et Sécurité

### **Q : Qui a accès à mes données personnelles ?**

**R :** L'accès à vos données est strictement contrôlé :

- **Vous** : accès complet à vos données
- **Médecins** : uniquement avec votre consentement
- **Équipe technique** : accès technique anonymisé uniquement pour maintenance
- **Personne d'autre** n'a accès à vos données personnelles

### **Q : Mes données sont-elles utilisées à des fins commerciales ?**

**R :** Non, jamais. Vos données personnelles de santé :

- Ne sont **jamais vendues** à des tiers
- Ne sont **pas utilisées** pour de la publicité
- Restent votre **propriété** exclusive
- Sont utilisées uniquement pour les services que vous demandez

### **Q : Puis-je supprimer définitivement mon compte ?**

**R :** Oui, vous exercez votre **droit à l'oubli** :

1. Demandez la suppression via les paramètres
2. Période de **réflexion** de 30 jours
3. **Suppression définitive** après confirmation
4. **Archivage légal** minimal si requis par la loi

### **Q : Comment exercer mes droits RGPD ?**

**R :** Vous pouvez facilement :

- **Consulter** vos données via "Mes données"
- **Corriger** des informations erronées
- **Exporter** vos données (format lisible)
- **Supprimer** votre compte
- **Contacter** notre DPO : dpo@plateforme-sante.fr

### **Q : Que se passe-t-il en cas de piratage ?**

**R :** En cas d'incident de sécurité :

- **Détection** automatique et immédiate
- **Confinement** rapide de la menace
- **Notification** dans les 72h (obligation légale)
- **Investigation** complète
- **Mesures** correctives et préventives

## Problèmes Techniques

### **Q : La plateforme est lente, que faire ?**

**R :** Essayez ces solutions :

1. **Vérifiez** votre connexion internet
2. **Videz** le cache de votre navigateur
3. **Désactivez** temporairement les extensions
4. **Utilisez** un navigateur récent et supporté
5. **Contactez** le support si le problème persiste

### **Q : Je ne reçois pas les emails de la plateforme**

**R :** Vérifiez :

1. **Dossier spam/indésirables** de votre boîte mail
2. **Adresse email** correcte dans votre profil
3. **Filtres** de votre messagerie
4. **Ajoutez** nos adresses à vos contacts
5. Si problème persiste, contactez le support

### **Q : L'application ne fonctionne pas sur mon téléphone**

**R :** Solutions à essayer :

1. **Mettez à jour** votre navigateur mobile
2. **Videz** le cache et les cookies
3. **Redémarrez** votre appareil
4. **Vérifiez** la compatibilité (iOS 13+, Android 8+)
5. **Utilisez** le mode navigation privée pour tester

### **Q : Mes données ne se synchronisent pas**

**R :** Points à vérifier :

1. **Connexion internet** stable
2. **Actualisez** la page (F5 ou Ctrl+R)
3. **Attendez** quelques minutes (synchronisation possible)
4. **Vérifiez** qu'aucune maintenance n'est en cours
5. **Contactez** le support avec détails

### **Q : J'ai perdu des données après une mise à jour**

**R :** Pas de panique :

1. **Actualisez** la page plusieurs fois
2. **Vérifiez** les archives/historique
3. **Reconnectez-vous** à votre compte
4. **Contactez** immédiatement le support
5. Nos sauvegardes permettent généralement la récupération
