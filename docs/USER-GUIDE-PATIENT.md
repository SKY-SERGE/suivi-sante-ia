# Guide Utilisateur Patient - Suivi Santé IA

## Bienvenue dans votre espace santé personnel

**Suivi Santé IA** vous accompagne dans le suivi de votre alimentation et de votre bien-être grâce à l'intelligence artificielle. Ce guide vous explique comment utiliser toutes les fonctionnalités de votre espace patient.

## 🚀 Premiers pas

### 1. Créer votre compte

1. Rendez-vous sur la page d'accueil
2. Cliquez sur **"S'inscrire"**
3. Remplissez le formulaire :
   - **Email** : Votre adresse email (elle servira de nom d'utilisateur)
   - **Mot de passe** : Au minimum 8 caractères avec une majuscule, un chiffre
   - **Prénom et nom** : Pour personnaliser votre expérience
   - **Date de naissance** : Pour des recommandations adaptées
4. Cliquez sur **"Créer mon compte"**
5. Vérifiez votre email et cliquez sur le lien de confirmation

### 2. Première connexion

1. Cliquez sur **"Se connecter"**
2. Saisissez votre email et mot de passe
3. Vous arrivez sur votre **tableau de bord personnel**

### 3. Compléter votre profil

Pour recevoir des recommandations personnalisées :

1. Cliquez sur votre nom en haut à droite > **"Mon profil"**
2. Complétez les informations :
   - **Poids et taille** : Pour calculer votre IMC
   - **Objectifs santé** : Perte de poids, maintien, prise de masse...
   - **Allergies alimentaires** : Pour éviter certains aliments
   - **Préférences** : Végétarien, sans gluten, etc.
3. Cliquez sur **"Sauvegarder"**

## 🍽️ Enregistrer vos repas

### Méthode 1 : Photo de votre repas (Recommandée)

L'intelligence artificielle analyse automatiquement vos photos pour identifier les aliments.

1. Dans votre tableau de bord, cliquez sur **"Nouveau repas"**
2. Sélectionnez le **type de repas** : Petit-déjeuner, Déjeuner, Dîner, Collation
3. Cliquez sur **"Prendre une photo"** ou **"Choisir un fichier"**
4. Prenez une photo claire de votre assiette :
   - ✅ **Bonne lumière** naturelle si possible
   - ✅ **Vue d'ensemble** de l'assiette
   - ✅ **Éléments distincts** bien visibles
   - ❌ Éviter les photos floues ou sombres
5. L'IA analyse votre photo et identifie les aliments
6. **Vérifiez et ajustez** les quantités si nécessaire
7. Ajoutez des **notes personnelles** (goût, sensation de satiété...)
8. Cliquez sur **"Enregistrer le repas"**

### Méthode 2 : Saisie manuelle

Si vous préférez saisir vos aliments manuellement :

1. Cliquez sur **"Nouveau repas"** > **"Saisie manuelle"**
2. Recherchez vos aliments dans la base de données
3. Ajoutez les quantités consommées
4. Sauvegardez votre repas

### Conseils pour de meilleures analyses

- **Photographiez avant de manger** pour une meilleure précision
- **Séparez les aliments** sur l'assiette si possible
- **Utilisez une assiette claire** pour un meilleur contraste
- **Ajoutez des détails** en notes si l'IA n'a pas tout identifié

## 📊 Suivre vos progrès

### Tableau de bord

Votre tableau de bord affiche :

- **Repas récents** avec analyse nutritionnelle
- **Graphiques de tendance** de vos apports caloriques
- **Progression vers vos objectifs** santé
- **Recommandations personnalisées** de l'IA

### Historique détaillé

1. Cliquez sur **"Historique"** dans le menu
2. Filtrez par période : Semaine, mois, année
3. Consultez :
   - **Calendrier des repas** avec photos
   - **Statistiques nutritionnelles** détaillées
   - **Évolution de vos habitudes** alimentaires

### Graphiques et analyses

L'application génère automatiquement :

- **Répartition nutritionnelle** : Protéines, glucides, lipides
- **Apports caloriques** : Comparaison avec vos besoins
- **Fréquence des aliments** : Vos aliments les plus consommés
- **Tendances temporelles** : Évolution sur plusieurs semaines

## 🎯 Définir et suivre vos objectifs

### Créer un objectif santé

1. Allez dans **"Mes objectifs"**
2. Cliquez sur **"Nouvel objectif"**
3. Choisissez un type d'objectif :
   - **Poids** : Objectif de poids cible
   - **Calories** : Limite quotidienne
   - **Nutrition** : Équilibre des macronutriments
   - **Habitudes** : Manger plus de légumes, boire plus d'eau...
4. Définissez votre **cible** et **délai**
5. L'IA vous proposera un **plan personnalisé**

### Suivre vos objectifs

- **Indicateurs visuels** : Barres de progression colorées
- **Notifications** : Rappels et encouragements
- **Recommandations** : L'IA ajuste ses conseils selon vos progrès
- **Célébrations** : Félicitations quand vous atteignez vos objectifs !

## 🤖 Utiliser le chatbot santé

### Poser des questions

1. Cliquez sur l'**icône chatbot** 💬 en bas à droite
2. Tapez votre question en français, par exemple :
   - "Combien de calories dans une pomme ?"
   - "Que puis-je manger pour augmenter mes protéines ?"
   - "Comment équilibrer mon petit-déjeuner ?"
3. Le chatbot vous répond avec des **informations nutritionnelles** fiables

### Types de questions supportées

- ✅ **Valeurs nutritionnelles** des aliments
- ✅ **Conseils d'équilibrage** des repas
- ✅ **Alternatives alimentaires** pour allergies/préférences
- ✅ **Explications** sur la nutrition
- ❌ **Diagnostic médical** (consultez un professionnel)
- ❌ **Prescriptions** ou conseils médicaux

### ⚠️ Important

Le chatbot fournit des informations générales. Pour des conseils médicaux personnalisés, consultez toujours un professionnel de santé.

## 👨‍⚕️ Partager avec votre médecin

### Donner accès à un médecin

1. Allez dans **"Paramètres"** > **"Partage médical"**
2. Cliquez sur **"Inviter un médecin"**
3. Saisissez l'**email de votre médecin**
4. Choisissez les **données à partager** :
   - Historique des repas
   - Analyses nutritionnelles
   - Objectifs et progrès
   - Recommandations IA
5. Définissez la **durée du partage**
6. Cliquez sur **"Envoyer l'invitation"**

### Gérer les autorisations

- **Consulter** qui a accès à vos données
- **Modifier** les autorisations à tout moment
- **Révoquer** l'accès si nécessaire
- **Historique** des consultations par les médecins

### Messagerie sécurisée

Échangez en toute sécurité avec vos médecins :

1. Cliquez sur **"Messages"**
2. Sélectionnez votre médecin
3. Rédigez votre message
4. **Joignez des rapports** automatiques si souhaité
5. Envoyez votre message chiffré

## ❓ Questions fréquentes

### Utilisation générale

**Q : Dois-je photographier tous mes repas ?**
R : C'est recommandé pour un suivi précis, mais vous pouvez aussi utiliser la saisie manuelle.

**Q : L'IA peut-elle se tromper ?**
R : Oui, c'est pourquoi vous pouvez toujours vérifier et corriger les identifications automatiques.

**Q : Puis-je utiliser l'app sans internet ?**
R : Les fonctions de base fonctionnent hors ligne, mais l'analyse IA nécessite une connexion.

### Données et vie privée

**Q : Mes photos de repas sont-elles stockées ?**
R : Les photos sont analysées puis supprimées. Seules les données nutritionnelles sont conservées.

**Q : Mon médecin peut-il voir toutes mes données ?**
R : Seulement ce que vous autorisez explicitement lors du partage.

**Q : Comment supprimer mon compte ?**
R : Dans Paramètres > Compte > Supprimer définitivement

### Problèmes techniques

**Q : L'analyse de photo ne fonctionne pas**
R : Vérifiez votre connexion internet et la qualité de la photo (lumière, netteté).

**Q : Je ne reçois pas les notifications**
R : Vérifiez les autorisations de notifications dans les paramètres de votre navigateur.

**Q : L'application est lente**
R : Essayez de rafraîchir la page ou vider le cache de votre navigateur.
